# Ashbel Nixon — Portfolio

Static, responsive portfolio for GitHub Pages. Built with HTML, CSS and JavaScript.

## Publish on GitHub Pages
1. Upload all files in this folder to the **root** of `ashbellikestocode/ashbel-portfolio` (replace files with the same names).
2. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`.
3. Save and wait for the Pages deployment in **Actions** to complete.
4. Open `https://ashbellikestocode.github.io/ashbel-portfolio/` and hard-refresh with `Ctrl + Shift + R`.

The site uses relative paths so the stylesheet, scripts, portrait, school photo and roadmap page work under the repository subpath.
